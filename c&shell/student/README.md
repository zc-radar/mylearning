# 学生成绩管理系统（C 语言面向过程）

一个简单的 Linux 命令行项目，使用 **C 语言面向过程**风格实现学生成绩管理。  
适合初学者练习：函数拆分、结构体、数组、文件读写、Makefile。

---

## 1. 功能列表

- 添加学生
- 显示全部学生
- 按学号查找
- 修改成绩
- 删除学生
- 统计信息（人数、平均分、最高分、最低分）
- 保存到文件并退出
